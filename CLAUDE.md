# MB-Skills

A collection of Claude Code agent skills.

## Agent skills

### Issue tracker

Issues live in GitHub Issues (via the `gh` CLI); external pull requests are a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map 1:1 to their own label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
